# Week 1: JavaScript Fundamentals

This folder contains introductory JavaScript exercises focusing on core logic, conditional statements, functions, and array manipulations.

## Exercises

- **BiggestOfTwoNumbers.js**: Logic to find the larger of two numbers.
- **Employee.js**: basic employee object/class structure.
- **LargestOfThreeNumbers.js**: Conditional logic to compare three numbers.
- **LargestOfThreeUsingFunctions.js**: Comparing three numbers using reusable functions.
- **SearchingAnElementInArray.js**: Implementation of search logic within an array.
- **SmallestNumberInAnArray.js**: Finding the minimum value in a numeric array.
- **SumOfArrayNumbers.js**: Calculating the total sum of elements in an array.
- **SumOfArrayUsingFunctions.js**: Summation logic encapsulated in a function.

## How to Run
You can run these scripts using Node.js:
```bash
node <filename>.js
```
