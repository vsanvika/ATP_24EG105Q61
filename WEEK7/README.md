# Week 7: Full Stack Blog Application

The culmination of the course, featuring a complete full-stack application with a frontend and backend.

## Project Structure

- **blog-app**: The root directory for the blog application.
    - **blog-app-frontend**: React frontend for reading and managing blog posts.
    - **blog-app-backend**: Node.js/Express backend for data persistence and API services.

## Key Features
- Dynamic article routing.
- Backend integration for post retrieval.
- Comprehensive UI components.

## Setup Instructions
Follow the individual README files within the frontend and backend folders for specific installation and execution steps.
