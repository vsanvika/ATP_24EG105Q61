- CSS Flexbox
- HTML Tables
- React Applications
- Tailwind CSS
- Component-based UI development

# ⚙️ Installation & Setup

## 📋 Prerequisites

Make sure you have installed:

- Node.js
- npm

---

# 1️⃣ Clone Repository

```bash
git clone <repository-url>

cd WEEK5
```

---

# 2️⃣ Install Dependencies

For React projects:

```bash
cd product-react-app

npm install
```

OR

```bash
cd user-react-app

npm install
```

OR

```bash
cd tailwind-project

npm install
```

---

# 3️⃣ Run Development Server

```bash
npm run dev
```

Application runs on:

```bash
http://localhost:5173
```
